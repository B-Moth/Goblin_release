⚙️ MODES EXPLAINED
────────────────────────────────────────────────────────────────────────────────

OFFLINE (Default) ✓
  • Works anywhere (no internet needed)
  • Free
  • Slower (~1-5 min per file)
  • Decent quality
  • No API key needed

ONLINE (Optional)
  • Needs internet & OpenAI API key
  • Costs ~$0.01-0.05 per file
  • Much faster (~10-30 sec per file)
  • Better quality
  • Get key: https://platform.openai.com/api-keys

See [MODES.md](guides/MODES.md) for detailed explanation.

❓ COMMON QUESTIONS
────────────────────────────────────────────────────────────────────────────────

Q: Where are my files saved?
A: In a "transcriptions/" folder (changeable in options)

Q: Why is it slow on first run?
A: Downloading offline models (~2 GB). Only happens once.

Q: Can I use my own API key?
A: Yes! Click 🔑 button and paste your key, then toggle to "En ligne"

Q: Is my data safe with online mode?
A: Yes. OpenAI doesn't store your files.

Q: Which model should I use?
A: tiny (fast), base (good), medium (best quality)

Q: Can I rename files?
A: Enable "Nommage intelligent" for AI-based auto-rename

🆘 TROUBLESHOOTING
────────────────────────────────────────────────────────────────────────────────

App won't launch?
  → Check Python version (needs 3.9+)
  → Reinstall: pip install -r REQUIREMENTS.txt
  → Try building again: python installers/build.py
    → Reinstall: pip install -r build/REQUIREMENTS.txt
    → Try building again: python build/installers/build.py

Permission denied (Linux)?
  → Run: chmod +x Goblin

Antivirus warning (Windows)?
  → It's safe (PyInstaller creates it this way)
  → Add Goblin.exe to whitelist if needed

App is slow?
  → First run downloads models (~2 GB), only happens once
  → Use smaller Whisper model (tiny) for speed
  → Use online mode for much faster processing

Files not saving?
  → Check that output folder path is valid
  → Ensure you have write permissions to the folder
  → Try using default "transcriptions/" folder
